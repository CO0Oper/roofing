# Ultimate Roof Repair Visual System

## Direction

A California road-maintenance field manual adapted into a homeowner-friendly roofing site. The page uses report grids, dispatch labels, safety color, oversized condensed type, and documentary imagery.

## Mode and dials

- Mode: Persuade.
- Design variance: 7.
- Motion intensity: 4.
- Visual density: 4.

## System

- Paper `#F2F0E7`, survey ink `#102739`, safety yellow `#F6C843`, annotation red `#C8442F`.
- Impact or narrow system display type with Arial body copy and monospace operational labels.
- Square corners, heavy rules, offset print-like shadows, and a light construction grid.
- One light visual world throughout. Yellow indicates calls to action; red marks proof and annotations.

## Imagery

Original generated documentary roof-inspection photography, clearly disclosed as illustrative concept imagery. Never claim it as completed Ultimate Roof Repair work.

## Interaction and responsive behavior

- One motivated hero photo reveal.
- Concern rows shift like selected report lines.
- Buttons compress their offset shadow on hover.
- Mobile stacks sections and keeps call and callback actions fixed at the bottom.
- Reduced-motion users receive the complete static composition.
